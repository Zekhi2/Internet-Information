四维时空里的人类社会（实体运转与现实信息、人类活动与人类知识）有什么-互联网的作用（利用实体运转，投射现实信息与人类知识，减少人类活动参与；集中人类因果交互）

**人类的输入-处理-输出模型**
- 输入
对实体的感知（视觉、听觉），对实体存在性的感知（感觉、直觉）
- 处理
归纳论思考（实体感知，从实体归纳原理）、目的论思考（实体存在性感知，从预设推演现实）
- 输出
主动，被动
